## 三、扩展普查新增失败信号（v0.2 八条规则外，10 条）

1. **致密化参数静默失效**（#1108/#741/#544）：配置存在但代码路径不消费 → 需"配置-代码一致性"检查 + clone/split/prune 分计数曲线
2. **高斯计数趋零前兆**（#875）：空张量 min() 崩溃前，活跃高斯数有下限预警窗口
3. **显存单调爬升 + 场景塌缩复合信号**（gsplat#614）：显存趋势作为 NaN 之外的第二前兆
4. **OOM 阶段定位**（#464 isect_tiles / #487 relocation）：发生阶段本身即归因线索
5. **渲染模式开关副作用**（gsplat#840 AA 致小高斯消失、#1224 h_var）：开关切换前后高斯数/锐度突变
6. **轨迹几何失败**（#804/#987 前向运动/窄基线）：需相机轨迹共线度指标（R2 管规模不管轨迹）
7. **分辨率-模糊交互**（#1146/#958/#467/#414）
8. **冷启动退化**（gsplat#872）：首跑 vs 复跑对照
9. **未初始化显存读（UB 不崩溃）**（gsplat#1031）：同 seed 双跑位级 diff
10. **评估管线"假质量差"**（#1239/#1078/#1074/#550）：先验证指标口径再归因训练

## 四、与 3dgs-training-debugger 知识库对齐（60 模式 / 8 大类）

技能库结构：60 个运行时失败模式（IF 初始化 6 / DF 致密化 8 / OF 优化 7 / MF 内存 6 / CF 收敛 7 / AF 伪影 8 / MF2 多GPU 6 / NF 新方法 12），每模式五元组（Symptom/Root Cause/Diagnostic/Fix/Expected Outcome）。

**覆盖关系结论**：
- **重叠最深**：R4（归因锚点 ↔ 库 Section 4.2 伪影-迭代定位决策树）、R5（参数体检 ↔ DF-06/AF-01/IF-02）、R6（NaN 前兆 ↔ 库监控表 grad norm 检查）——库中已有人工原型，GaussWatch 将其自动化
- **库外新增**（R2/R3/R7/R8 的核心检测点）：relocated/alive 比值、tile 交点、dead fraction 曲线、导出保护、编译 flags 检查——库中完全没有，来自本轮 issue 实证
- **互补提醒**：库的 104 静态 bug 模式归 3dgs-code-reviewer 分工（编码期），GaussWatch 只做运行期——边界清晰

## 五、规则库 v2：R1-R16

R1-R8 维持 v0.2 定义（issue 实证），新增 R9-R16（来源：技能库模式转化，每条绑定出处）：

| 规则 | 内容 | 来源（技能库模式） | 优先级 |
|---|---|---|---|
| R9 | **VRAM-计数失联**：高斯计数稳定而 VRAM 单调增长（线性拟合判定）→ 缓冲泄漏/优化器膨胀 | MF-05 + MF-03 | P0 |
| R10 | **eval 剪刀差**：train/test PSNR gap >3-5dB 或见顶后连降 → 过拟合/数据问题 | CF-03 + CF-05 | P1 |
| R11 | **loss 分量失衡**：reg loss >10× 渲染 loss、mask 覆盖 >90% 或反转 | OF-04 + OF-06 | P1 |
| R12 | **梯度归零检测**：grad norm 恰好 ==0（静默失败：计算图断裂），与 R6 的突变方向互补 | OF-03 + 库监控表 | P0 |
| R13 | **剪枝比例带**：单次 prune 移除 >5% 告警（正常只删透明高斯） | DF-05 | P1 |
| R14 | **初始化自检包**：iter<100 三步——scale==0 检查 / max scale 越界 / 位姿渲染与输入图像比对 | IF-02 + IF-03 + IF-04 | P0 |
| R15 | **跨 run 方差**：同配置多种子方差 >0.5dB → 非确定性算子 | CF-07 | P2 |
| R16 | **致密化一致性**：clone/split/prune 分计数曲线 + max_radii2D 等参数生效验证（v0.3 信号 1） | F6a issue 实证 | P1 |

配套扩展：R3 事件曲线族纳入 opacity reset 周期回归（DF-07）为第三类周期事件；R4 归因锚点增"评估锚点"（F6c：先验证指标口径再归因训练）与"ADC→参数体检"自动联动（库决策树自动化）。

**规则库总计 16 条**：P0 六条（R1/R6/R12/R14 + R2/R3 核心子集）、P1 六条（R10/R11/R13/R16 + R5/R7）、P2 四条（R15 + R8 部分场景 + F6d/e/f 外围建议输出）。
